# 🏥 SmartCare Hospital Management System

A modern, responsive, and interactive web portal for hospital management. This project provides a comprehensive suite of digital healthcare services, designed to streamline patient care and hospital operations.

## 🌐 Live Demo
👉 **[Visit SmartCare Hospital Live](https://YOUR_USERNAME.github.io/SmartCare-Hospital/)**

## ✨ Features
- **🏠 Home Dashboard:** A welcoming landing page with quick access to all hospital services, key statistics, and a modern UI.
- **📅 Online Appointments:** Book doctor appointments online by selecting the department, preferred doctor, date, and time.
- **📂 Digital Medical Records:** Secure portal to view past diagnoses, prescriptions, and download medical history.
- **🚑 Emergency Ambulance:** A rapid-response ambulance booking form with emergency priority levels.
- **🩸 Blood Bank:** A dual-form system allowing users to register as blood donors or request blood units.
- **🤖 AI Symptom Checker:** An interactive tool where patients input symptoms to get a simulated urgency assessment.
- **🏋️ Fitness & Diet Planner:** A personalized tool to calculate BMI and generate basic fitness/diet plans based on user stats.
- **👴 Elderly Care:** A dedicated monitoring dashboard to register senior patients and track their vitals (Heart Rate, BP, Oxygen).
- **📱 Fully Responsive:** The layout adapts beautifully to mobile phones, tablets, and desktops.
- **✨ Modern Animations:** Smooth hover effects, glowing cards, and transitions for an engaging user experience.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for all 8 pages.
- **CSS3:** Custom styling, flexbox, CSS grid, and keyframe animations.
- **JavaScript:** Client-side interactivity and form handling.
- **Font Awesome:** Icons for UI enhancement.
